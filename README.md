# schedule_claude

Repositorio para el registro automático de ejecuciones programadas.

Una tarea recurrente agrega una línea a `hello_log.txt` cada vez que se ejecuta, con la fecha y hora UTC de la corrida.

## Contenido

- `hello_log.txt` — bitácora de ejecuciones (una línea por corrida).
- `README.md` — este archivo.
